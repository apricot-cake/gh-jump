データとプライバシー

GitHubへのアクセス

gh jumpはGitHub CLIを使い、GitHub.comのアカウント名とアクセス可能なリポジトリを取得します。認証情報はGitHub CLIが管理し、拡張はトークンを取り出したり保存したりしません。

ローカルキャッシュ

リポジトリのID、所有者、名前、private・forkの情報と取得時刻を、%LOCALAPPDATA%\GHJump\Cacheに暗号化されていないJSONとして保存します。ファイル名にはアカウント名が含まれ、privateリポジトリ名も保存されることがあります。通常は5分間キャッシュを使います。

検索は取得済みの一覧に対してローカルで行います。削除する場合はコマンドパレットを終了して、このキャッシュフォルダーを削除してください。アプリのアンインストール後もキャッシュが残る場合があります。

ブラウザーで開くページ

アクションは既定のブラウザーでGitHubのURLを開きます。ページの閲覧にはブラウザー側のGitHubログインを使います。IssueやPull requestを自動で投稿することはありません。

開発者への送信

拡張に広告、利用状況の分析、開発者が運営するサーバーはありません。このページにもアクセス解析を組み込んでいません。GitHub、GitHub CLI、ブラウザー、PowerToys、Microsoft Store、GitHub Pagesには、それぞれの設定とポリシーが適用されます。

お問い合わせ

GitHub Issuesへお願いします。公開されるため、トークンやprivateリポジトリの情報を含めないでください。
